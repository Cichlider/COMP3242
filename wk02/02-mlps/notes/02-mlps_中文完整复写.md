# Week 2 Linear Classifiers and MLPs（中文完整复写）

## 本周总览
- 本周主题从二分类线性分类器出发，连接到 logistic regression、MLP、多分类与优化。
- 课程主线是：模型表达能力 -> 损失函数 -> 梯度计算 -> 训练算法。

## 二分类线性分类
- 数据集由特征 `x \in R^n` 与标签 `y \in {0,1}` 组成。
- 线性分类器通过超平面 `a^T x + b = 0` 划分样本空间。
- `a^T x + b` 可解释为到分类边界的有符号距离（比例意义）。

## Logistic Regression
- 使用 sigmoid 将线性打分映射为概率：`P(y=1|x)=\sigma(a^T x+b)`。
- 参数通过最大似然或等价交叉熵最小化来学习。
- logistic regression 可看成“单神经元”模型。

## 正则化与温度缩放
- 正则化通过惩罚参数幅值抑制过拟合，提高泛化。
- 温度缩放可在后处理阶段调整概率分布的尖锐程度（校准置信度）。

## XOR 问题与多层结构必要性
- XOR 不能由单条线性边界分开，说明单层线性模型表达能力不足。
- 引入隐藏层后，通过特征重映射可实现 XOR 的可分。

## MLP（多层感知机）
- 两层 MLP 形式可写为：`y = c^T \phi(Ax+b)+d`。
- 其中 `\phi` 为逐元素激活函数，常见有 sigmoid、tanh、ReLU。
- 网络参数包括每层权重与偏置，前向传播按层级组合。

## 通用逼近定理（直观）
- 在合适激活函数条件下，单隐藏层网络可逼近任意连续函数。
- 该定理说明“可表达”，但不直接给出高效训练与参数规模上界。
- 深层网络在参数效率与分层特征表达上通常更具优势。

## 多分类与多标签
- 多分类：softmax 输出 `K` 类概率，通常配合 cross-entropy。
- 多标签：每类独立 sigmoid，常用 binary cross-entropy。
- 二者本质区别是标签约束：互斥单选 vs 非互斥多选。

## 常见损失函数
- 回归常用 MSE。
- 分类常用交叉熵（CE / BCE）。
- 0-1 loss 反映最终分类准确性，但不可导，通常不用作直接优化目标。

## 梯度下降优化
- 参数更新核心：沿负梯度方向迭代。
- 学习率决定步长，过大可能发散，过小收敛慢。
- 深度学习中多用预设 schedule 或自适应优化器。

## 多元微积分与梯度回顾
- 梯度向量由各偏导组成，表示函数上升最快方向。
- 链式法则是多层网络反向传播的基础。
- 反向传播的本质是复用中间量高效计算参数梯度。

## 手推梯度示例（两层感知机）
- 对 `y = c^T\sigma(Ax+b)+d` 可分解求导：
  - 先对输出层参数求导（`c,d`）
  - 再通过链式法则回传到隐藏层参数（`A,b`）
- 重点是维度一致性与逐元素乘法（Hadamard product）处理。

## PyTorch 训练实现
- 典型训练循环：DataLoader -> forward -> loss -> backward -> step -> zero_grad。
- `torch.nn.CrossEntropyLoss` 用于多分类时输入 logits（无需手动 softmax）。
- 调试重点：shape 对齐、标签类型、梯度清零时机。
